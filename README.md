# Agent-PersonalinfoManager 个人信息管家

一个「个人信息管家 Agent」Web 应用：帮助用户记录零散的想法、资料和待办，自动完成分类、总结和内容关联，并提供关键词检索、智能问答、重点信息提取、待办整理，以及阶段总结与后续行动建议。

- **在线地址**：https://wbapp-p1tdz5eh3hkhipqm1imeks.app.workbuddy.host/?sharecode=NPG6EFUZET
- **技术形态**：零依赖单文件应用（`index.html`，HTML + CSS + JS），双击即可在浏览器中运行，无需构建工具
- **数据存储**：当前版本保存在浏览器 `localStorage`（键名 `pib_items_v1`）

## 一、已实现的功能

### 1. 快速记录（首页）
- 单一输入框随手记录，支持 ⌘/Ctrl + Enter 快捷保存
- 类型可「智能识别」或手动指定为 **想法 / 资料 / 待办**
- 保存时自动走一遍加工管线（详见「技术说明」）：

```
保存条目 → 类型识别 → 自动分类 → 关键词提取 → 摘要生成 → 重点信息抽取 → （待办）截止时间解析
```

### 2. 自动分类与总结
- 按内容自动归入 **工作 / 学习 / 生活 / 财务 / 健康 / 创意** 六大类别（关键词命中计分），无法命中时归入「未分类」
- 超过 60 字的内容自动生成首句式摘要，在卡片和详情页中展示

### 3. 内容关联
- 基于关键词 Jaccard 相似度 + 类别/类型加成，自动为每条记录推荐最多 4 条相关内容
- 卡片上直接预览关联摘要，详情弹窗中可点击跳转到关联条目，形成「知识网络」浏览体验

### 4. 关键词检索
- 顶栏搜索框全库检索，支持**多关键词 AND 组合**（空格分隔），匹配范围覆盖正文、关键词、分类
- 命中片段以 `<mark>` 高亮显示，配合「类型 × 分类」双重筛选器精确定位

### 5. 重点信息提取
- 保存时自动识别并归类六类关键信息：**日期、时间、链接、@人物、金额、电话**
- 在条目卡片（前 4 项）和详情页完整展示

### 6. 待办整理
- 自动解析自然语言截止时间：「明天下午3点」「后天」「本周五」「12月20日」「下周三」等
- 截止时间颜色分级：**逾期红色 / 2 天内黄色 / 其余灰色**
- 勾选完成（带删除线）、重新打开、删除；列表按「未完成在前 + 截止时间升序」排列

### 7. 智能问答
- 用自然语言基于已有记录提问，例如：
  - 「我这周还有什么没做？」→ 触发待办盘点意图，列出未完成事项及逾期状态
  - 「关于 xx 我都记了什么？」→ 关键词加权检索（关键词命中 ×3 分、正文命中 ×1 分），取前 5 条生成回答
- 回答附带「依据」条目链接，点击可查看原始记录

### 8. 阶段总结与行动建议
- 支持 **近 7 天 / 近 30 天 / 全部** 三个统计范围，报告包含：
  - KPI 总览（想法/资料/待办数量、完成数、逾期数）
  - 分类分布（条形图）
  - 高频主题（跨条目关键词聚合）
  - 待办进展
  - **后续行动建议**：规则引擎生成，覆盖逾期处理、待办积压、想法落地、资料消化、精力过度集中、完成度激励等 6 类场景
- 一键复制报告到剪贴板

### 9. 数据备份
- 导出：全部条目一键导出为带日期的 JSON 备份文件
- 导入：按条目 id 去重合并，不覆盖已有数据

### 10. 其他
- 首次运行自动注入 5 条示例数据（想法×2、资料×1、待办×2），便于快速体验，可自行删除
- 响应式布局：窄屏（<760px）下侧栏收缩为图标模式
- 明亮主题，中文界面

## 二、重要说明

1. **当前为本地实现版本。** 开发时云服务激活未获确认，因此本版数据保存在浏览器 `localStorage` 中，智能分析由本地规则引擎完成。这意味着：
   - **换浏览器、换设备、清除浏览器数据都会导致记录丢失或不可见**（不同步）
   - 智能问答和阶段总结基于关键词匹配与规则，**不是真正的语义理解**，对同义改写、隐含意图的识别能力有限
   - 建议**养成定期导出备份的习惯**（顶栏「导出备份」）
2. **数据模型已按云端结构预留。** 条目采用文档型结构（id / type / content / category / keywords / summary / highlights / createdAt / done / due），与云端数据库的文档模型一一对应，后续迁移云端时前端 Store 层只需替换读写实现，加工管线可保留。
3. **分类依赖关键词词典。** `CATS` 词表是人工维护的，遇到新领域词汇会归入「未分类」，需要持续补充词表。
4. **截止时间解析是相对的。** 「明天」「下周三」等以记录时刻为基准计算，不随时间推移自动更新；逾期只做标记，不做自动改期。
5. **隐私性。** 数据完全在本机浏览器内，不上传任何服务器（当前版本），适合隐私敏感内容。

## 三、后续修改与优化方向

### A. 架构升级（优先级高）
| 优化项 | 说明 |
|---|---|
| **接入云端数据库** | 将 Store 层从 localStorage 迁移至云端文档数据库，实现跨设备同步与持久化；数据结构已兼容，改动集中在 `Store` 对象的 `load/save/add/update/remove` 五个方法 |
| **接入大模型（LLM）** | 用语义模型替换本地规则引擎，升级点：① 问答改为 RAG 检索增强生成；② 分类改为语义分类，摆脱词典限制；③ 摘要改为真正的语义摘要；④ 阶段总结改为 LLM 生成的深度分析 |
| **增加用户登录** | 接入账号体系后实现按用户隔离数据，支持多端一致 |

### B. 功能增强（优先级中）
- **全文分词检索**：当前多关键词检索基于 `includes` 子串匹配，可升级为分词后按词检索，提升中文命中率
- **标签系统**：在自动分类之外支持用户自定义标签，补足机器分类的偏差
- **条目编辑**：当前只有删除，缺少正文修改功能
- **编辑器增强**：支持 Markdown 渲染、图片附件（需接云存储）
- **待办优先级**：增加「重要且紧急」四象限视图（目前仅建议中提及）
- **回顾提醒**：周期性（如每周一）推送阶段总结，待办到期提醒

### C. 体验优化（优先级低）
- 深色主题
- 移动端手势优化（滑动完成/删除待办）
- 关联图谱可视化（把条目关联渲染成力导向图）
- 多语言界面

## 四、技术说明（供二次开发参考）

| 模块 | 位置 | 实现要点 |
|---|---|---|
| 数据层 `Store` | `LS_KEY` 起 | localStorage CRUD，`all/add/update/remove` 四个方法，迁移云端时替换此层 |
| 中文分词 `tokenize` | 轻量 NLP 区 | 中文按 2-gram 滑窗 + 英文整词，`STOP` 停用词表过滤 |
| 关键词 `keywordsOf` | 同上 | 词频排序，短词需出现 2 次以上 |
| 分类 `classifyOf` | 同上 | `CATS` 六类词典命中计分，最高分者胜 |
| 类型识别 `detectType` | 同上 | 正则匹配「待办/记得/别忘」→ todo，「http/资料/收藏」→ material，其余 → idea |
| 截止解析 `dueOf` | 同上 | 「明天/后天/下周X/X月X日/X点」正则 + 相对日期计算 |
| 关联 `relatedOf` | 同上 | 关键词 Jaccard 相似度 + 类别(0.05)/类型(0.03)加成 |
| 问答 `ask` | 视图区 | 待办意图正则优先；否则关键词加权检索（kw 命中 3 分 / 正文 1 分），取前 5 条模板化生成回答 |
| 报告 `buildReport` | 视图区 | 统计聚合 + 6 类行动建议规则引擎 |

- **视图切换**：五个视图（home/items/todo/qa/report）共用一个渲染函数映射 `rerender()`，无路由库，纯 DOM 操作
- **已做验证**：JS 语法检查通过；NLP 管线冒烟测试通过（类型识别/分类/关键词/截止解析/重点抽取/关联推荐）
